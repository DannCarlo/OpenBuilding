I. Database v16.0
21
AISC Shapes Database v16.0 is an update to Shapes Database v15.0. This version is consistent with shape properties and dimensions tabulated in the AISC Steel Construction Manual, 16th Edition, 1st Printing. The database contains some additional section properties that are not included in the Manual.
